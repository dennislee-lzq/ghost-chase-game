# Ghost Chase - 鬼抓人游戏设计

## 1. 游戏概述

- **类型**: 俯视角恐怖躲藏游戏
- **平台**: 浏览器 (HTML5 Canvas)
- **玩家人数**: 1 人 (玩家) vs AI (鬼)
- **核心循环**: 在程序生成的迷宫中躲避 AI 鬼，收集 5 个物品后从出口逃脱

## 2. 游戏机制

### 玩家 (逃跑者)
- **移动**: WASD 键控制方向
- **速度**: 150 像素/秒
- **碰撞**: 无法穿过墙壁
- **道具**: 每局可携带 3 个道具（战前选择）

### 鬼 (AI 追捕者)
- **移动**: 每秒 120 像素
- **AI 行为**:
  - 视野范围 200 像素
  - 视野角度 90 度
  - 巡逻模式: 未发现玩家时随机移动
  - 追逐模式: 发现玩家后直线追击
- **技能**:
  - 瞬移 (Teleport): 每30秒可用，传送到玩家附近某处
  - 加速冲刺 (Ghost Rush): 追逐时速度提升50%，持续2秒

### 地图
- **生成方式**: 程序随机生成
- **尺寸**: 800x600 像素画布
- **墙壁**: 随机生成，有边界限制
- **物品**: 地图上随机分布 8 个物品点
- **出口**: 地图角落某处，需要收集 5 个物品后激活

### 道具系统
| 道具 | 效果 | 冷却时间 |
|------|------|----------|
| 加速药水 (Speed Boost) | 3秒内速度翻倍 | 30秒 |
| 隐形药水 (Invisibility) | 3秒内鬼无法追踪 | 45秒 |
| 烟雾弹 (Smoke Bomb) | 原地释放烟雾，干扰鬼的视线3秒 | 60秒 |

### 胜负条件
- **胜利**: 收集 5 个物品并到达出口
- **失败**: 被鬼抓住 (碰撞检测)

## 3. 游戏流程

1. **开始界面**: 游戏标题 + "开始游戏" 按钮
2. **道具选择**: 从3种道具中选1个携带
3. **游戏开始**: 玩家出现在地图一角，鬼在对面角落
4. **游戏中**: 收集物品、躲避鬼、使用道具
5. **结束界面**: 显示 "胜利" 或 "失败"，重玩按钮

## 4. 视觉风格

| 元素 | 颜色 |
|------|------|
| 背景 | 深灰色 #1a1a2e |
| 墙壁 | 深紫色 #16213e |
| 玩家 | 白色圆点 + 发光效果 |
| 鬼 | 红色半透明 + 脉动效果 |
| 物品 | 金色发光点 |
| 出口(未激活) | 灰色 |
| 出口(已激活) | 绿色光圈 |
| 鬼视野 | 淡红色锥形区域 |

## 5. 技术实现

- **单文件**: 全部代码在一个 HTML 文件中
- **渲染**: Canvas 2D API
- **循环**: requestAnimationFrame
- **碰撞**: AABB 矩形碰撞检测
- **地图**: 简单的房间分割算法
